# Squirzilla — Creature Motion Study

Squirzilla의 제작 의도, 리깅 구성과 최종 12개 모션을 소개하는 정적 웹페이지입니다.

- 프롬프트는 최종 요구사항을 정리한 문장이며 대화 원문 인용이 아닙니다.
- 영상은 Blender 모션 프리뷰입니다. 실제 Unity 실행 영상이 아닙니다.
- 모델 원본, FBX, 개인 작업 기록은 이 저장소에 포함하지 않습니다.
- `index.html`, `style.css`, `app.js`, `clips.json`, `assets/`로 구성됩니다.
- GitHub Pages: main 브랜치의 루트에서 배포합니다.
