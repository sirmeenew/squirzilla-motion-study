제작 요청 요약

  • 초거대 괴수에 맞는 느린 준비·회복 동작과 무게감.
  • Idle은 고개를 조금 숙이고 입을 약간 연 자세.
  • 좌우 회전은 각각 45도, 빔 스윕은 총 30도.
  • 잠수 → 꼬리만 보이는 수영 → 솟아오르며 포효 → Idle.
  • 사망은 포효 → 무릎 꿇기 → 호숫가에 천천히 앞으로 쓰러지기.
